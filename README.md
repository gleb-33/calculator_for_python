# Python GUI Calculator

A simple calculator application built with **Python** and **CustomTkinter**. It provides a graphical interface for performing basic mathematical calculations.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Squaring numbers
- Decimal number support
- Clear all (`AC`) and delete last character (`⌫`) buttons
- Dark-themed graphical user interface
- Large, easy-to-use buttons

## Requirements

- Python 3.8 or newer
- CustomTkinter

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR-REPOSITORY
   ```

3. Install the required dependency:

   ```bash
   pip install customtkinter
   ```

## Usage

Run the calculator with:

```bash
python Calculator.py
```

Use the on-screen buttons to enter numbers, select an arithmetic operation, and calculate the result.
